# Eco-Ride System: City Scooter Sharing & Testing Module (POM Architecture)

Кастомный объектно-ориентированный программный модуль для управления городской системой шеринга самокатов (велошеринга). Проект полностью спроектирован с нуля, содержит интерактивный симулятор, скрипты баз данных и покрыт автоматическими тестами по правилам коммерческой QA-автоматизации.

## 🚀 Стек технологий & Архитектура
* **Python 3** - написание чистой объектно-ориентированной логики (классы, методы, инкапсуляция состояний).
* **Pytest** - автоматизация тестирования критических узлов системы (`assert`-проверки граничных значений) [Example 5].
* **Page Object Model (POM)** - архитектурное разделение проекта на независимые слои: логика самоката изолирована в `scooter.py`, а тестовые сценарии вынесены в `test_scooter.py` .
* **SQL** - аналитические скрипты для работы с реляционными базами данных (фильтрация, агрегация данных) [Example 5].

## ⚙️ Функционал системы
* **Ядро шеринга (`scooter.py`):** Контроль заряда батареи, динамический расчёт пробега и автоматическое управление блокировкой замка безопасности.
* **Интерактивный симулятор (`main.py`):** Консольный текстовый интерфейс, позволяющий пользователю в реальном времени управлять самокатом, совершать поездки и ставить его на зарядку .
* **База данных (`database.sql`):** Комплекс готовых SQL-запросов для мониторинга флота самокатов (поиск разряженных устройств, подсчёт активных сессий, агрегация общего количества техники) .

## 🧪 Покрытие автотестами
Проект защищён юнит-тестами, которые проверяют граничные сценарии:
1. Корректность запуска поездки (списание батареи, начисление пробега, разблокировка замка).
2. Защитная логика при нулевом заряде (блокировка старта поездки разряженного самоката ради безопасности пользователя).
Используйте код с осторожностью.
